# Cottage Video

Self-hosted / Open Source video surveillance system for a private house.

## Current stage

One camera connected to the local network:

- IP: 192.168.0.10
- Port: 34567
- Client: Optimus Connect

## Development environment

- WSL / Ubuntu 24.04
- Python
- Docker
- Git / GitHub
