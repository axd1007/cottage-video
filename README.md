Web-интерфейс работает через O20/JFTech VideoPlayTool.

Установлены:

VideoPlayTool.exe
VideoPlugin_x64.exe

Web-интерфейс использует локальный plugin API и обращается к камере через TCP 34567.

Порт 8899 — Web Viewer, а не основной канал управления настройками.

Детекция и аналитика

В интерфейсе камеры обнаружены настройки:

детекция движения;
саботаж;
потеря сигнала;
тревожные входы/выходы;
видеоаналитика;
детекция людей;
обнаружение лиц;
заполнение диска;
ошибка диска;
CarShape.

Изменение этих параметров не вызывает обычные Fetch/XHR-запросы браузера. Предполагается передача команд через локальный VideoPlayTool/plugin и proprietary-протокол камеры по TCP 34567.

Следующий шаг исследования протокола — захват TCP-трафика 192.168.0.10:34567 при изменении одного параметра.
