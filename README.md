# Cottage Video

Self-hosted система видеонаблюдения для частного дома.

## Текущий этап

Этап 1 (одна камера → стабильный поток) в основном завершён. Дальше — выбор и развёртывание NVR.

## Окружение

- WSL / Ubuntu 24.04
- Python ≥ 3.11
- Git / GitHub
- GPU NVIDIA (CUDA) — аппаратное декодирование
- Docker — пока не используется

## Камера

Одна камера в локальной сети (вне общего доступа).

| | |
|---|---|
| IP | 192.168.0.10 |
| RTSP | порт 554 |
| Проприетарный протокол | TCP 34567 |
| Web Viewer | порт 8899 |

### Потоки

| Поток | URL | Кодек | Разрешение | FPS | Аудио |
|---|---|---|---|---|---|
| Основной | `rtsp://<admin>:<123>@192.168.0.10:554/stream=0` | H.265 / HEVC Main | 2592×1944 | 25 | PCM A-law, 64 kbps |
| Дополнительный | `rtsp://<admin>:<123>@192.168.0.10:554/stream=1` | H.265 / HEVC | 352×288 | 15 | PCM A-law, 64 kbps |

Учётные данные хранятся в `.env` (см. `.env.example`), в репозиторий не попадают.

### Управление и аналитика камеры

- Web-интерфейс работает через O20/JFTech VideoPlayTool (`VideoPlayTool.exe`, `VideoPlugin_x64.exe`) и локальный plugin API.
- Настройки камеры передаются по проприетарному протоколу через TCP 34567. Разбирать протокол не планируется: проект использует только RTSP.
- Встроенные функции камеры: детекция движения, саботаж, потеря сигнала, тревожные входы/выходы, видеоаналитика, детекция людей и лиц, ошибки диска, CarShape.

## Проверено

- RTSP-доступ к основному и дополнительному потоку.
- Аппаратное декодирование на GPU:

```bash
ffmpeg -hide_banner -hwaccel cuda -hwaccel_output_format cuda \
  -i tests/test1.mp4 -f null -
```
