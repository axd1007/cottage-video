Алгоритм разработки

Этап 1. Одна камера → стабильный поток

Подключить камеру к ноутбуку по локальной сети.
Проверить RTSP: основной поток + substream.
Проверить H.265/H.264, разрешение, FPS, bitrate.
На WSL организовать доступ к RTSP.
Научиться получать и просматривать поток средствами Linux/Python.
